## 🐛 Sorun mu Var?

### Frontend Değişiklik Göstermiyorsa:
1. Sayfayı **hard refresh** yap: `Ctrl + Shift + R` (Windows) veya `Ctrl + F5`
2. Tarayıcı cache'ini temizle
3. Geliştirici konsolunu aç (F12) ve hataları kontrol et

### Backend Hatası:
```bash
cd backend
python -m uvicorn main:app --reload --port 8000
```

### Frontend Hatası:
```bash
cd frontend
npm run dev
```

### Cache Sorunu:
- Ctrl + Shift + Delete → Cache'i temizle
- Veya: Gizli pencere aç (Ctrl + Shift + N)
